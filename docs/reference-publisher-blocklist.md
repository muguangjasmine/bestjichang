# 第三方参考发布者与来源网站隔离黑名单 (Internal Reference Publisher Blocklist)

## 1. 隔离规则概述
根据建站总指令中“四 B 参考博客名称隔离与公开页面资料展示规则”的要求：
- 用户提供的参考文档、评测文章、排行榜、截图仅作为内部事实整理参考。
- 严禁将参考发布者的名称、域名、作者名、自称及“根据某某博客”等句式输出到任何公开页面、文章正文、标题、摘要、图片 ALT 或 JSON-LD 结构化数据中。
- 构建后必须执行自动化扫描，若发现泄漏必须立即拦截并修正。

## 2. 核心黑名单词汇表
以下词汇严禁在 `public/` 静态产物中出现：
- `三毛机场`
- `猫梦博客`
- `Gaterank`
- `星维机场`
- `一毛机场`
- `一份机场`
- `二毛博客`
- `根据某某博客`
- `某评测站称`
- `资料来自某博客`
- `在某站未检索到`
- `根据某博主`

## 3. 自动化合规保障机制
在 `scripts/verify-site.js` 验证脚本的第 6 项测试中，会对全站静态生成的文件进行遍历深度匹配扫描，确保泄漏计数（leakCount）严格等于 0。
