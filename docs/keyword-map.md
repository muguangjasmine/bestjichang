## 2. 关键词与内容质量标准
- 每篇文章设置且仅设置 1 个主搜索意图词，搭配 3~8 个辅助与长尾词。
- 正文净中文字符严格控制在 800~1200 字之间（精简高效，杜绝废话空话）。
- 任何推广外链统一配置 `rel="sponsored nofollow noopener"`。
- 严禁出现第三方参考博客（如三毛机场、猫梦博客等）任何字眼。
