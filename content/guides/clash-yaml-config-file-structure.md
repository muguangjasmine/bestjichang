## 常见疑问解答

### 打开一个标准的Clash YAML配置文件，其最核心的三大基础顶层语法板块分别是什么？

三大支柱板块为：①‘proxies’（节点列表：定义每个节点的服务器地址与加密参数）；②‘proxy-groups’（策略组：将节点组织成自选、自动测速或故障转移）；③‘rules’（规则集：定义哪些域名走哪个策略组）。

### 在手动编辑修改YAML文件时，导致客户端报错崩溃最常见且致命的语法低级错误是什么？

是‘空格缩进错误’与‘使用了中文全角字符’。YAML对层级缩进极其严苛（必须使用半角空格缩进，严禁使用Tab键制表符），任何一行多敲或少敲一个空格都会导致解析器直接抛出Parse Error。
