在现代家庭数字娱乐生活中，任天堂 Switch 游戏主机、索尼/小米智能电视、Apple TV 以及各类非智能物联设备，往往因系统封闭性限制无法直接安装 Clash 等现代代理客户端，导致看不了外网 4K 电视或者外服联机频繁报错。其实，只需利用电脑或安卓手机上正在运行的 Clash 客户端开启“局域网共享（Allow LAN）”功能，就能以零额外硬件成本，让客厅全屋设备瞬间畅享极速网络。

## 一、局域网共享代理的底层工作原理

所谓“允许局域网连接（Allow LAN）”，是指将运行在电脑或手机上的 Clash 代理监听端口，从默认的“仅限本地回环（127.0.0.1）”扩展绑定至本地局域网的物理网卡 IP 地址（如 192.168.1.100）。此时，这台电脑便化身为局域网内的一台微型代理网关服务器。同一 Wi-Fi 网络下的其他终端只需在网络设置中将 HTTP/SOCKS 代理指向这台电脑的 IP 与端口，即可借道实现全量翻墙加速。

## 二、主机端配置实操：一键开启与局域网 IP 定位

第一步，在 Windows/Mac 电脑端的 Clash Verge Rev 设置中，找到并开启“允许局域网连接（Allow LAN）”开关；第二步，获取电脑在当前家庭 Wi-Fi 中的内网 IP 地址：Windows 用户按下 Win+R 输入 cmd，执行 ipconfig 回车，找到“无线局域网适配器”下面的 IPv4 地址（例如 192.168.31.50）；第三步，确保 Windows 防火墙弹出权限提示时勾选了“允许专用网络访问”，防止防火墙在内网层面拦截来自其他设备的握手请求。

## 三、终端设备接入：以 Switch 与智能电视设置为例

以任天堂 Switch 为例：进入主机“系统设置-互联网-互联网设置”，找到已连接的家庭 Wi-Fi 点击“更改设置”，将底部的“代理服务器设置”从关闭改为“开启”。在服务器一栏准确填入电脑的局域网 IP（如 192.168.31.50），在端口一栏输入 Clash 的混合端口（默认 7890），点击保存并进行连接测试。智能电视盒子也是相同逻辑，在 Wi-Fi 高级设置中填入手动代理即可畅看 YouTube 4K。

## 常见疑问解答

### Switch 或电视填好了代理 IP 和端口，为什么仍然提示“无法连接到代理服务器”？

80% 的原因在于电脑端的 Windows Defender 防火墙拦截了入站连接。可临时在 Windows 安全中心关闭防火墙进行测试，或在高级防火墙设置中为 7890 端口创建一条允许入站的自定义规则。

### 电脑合盖休眠或者关机后，Switch 和电视盒子还能继续通过代理上网吗？

不能。局域网共享模式要求作为代理源宿主机的电脑必须始终处于开机且客户端正常运行的状态；若需要 7×24 小时全天候免开电脑的共享加速，建议选购部署软路由或在路由器刷入 OpenWrt。

## 总结与选购自检建议

物尽其用是网络极客的美德。无需额外采购昂贵的专业路由硬件，仅需巧用 Allow LAN 局域网共享，就能让客厅娱乐全家桶瞬间解锁跨国互联的无限精彩。
